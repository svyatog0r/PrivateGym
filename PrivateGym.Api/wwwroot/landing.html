PrivateGym: Аренда индивидуальных залов

Традиционные фитнес-клубы часто ассоциируются с очередями к тренажерам, шумом и нехваткой личного пространства. PrivateGym — это платформа для бронирования изолированных тренировочных помещений. Сервис позволяет клиентам арендовать залы наедине с собой или в кругу близких, обеспечивая максимальный комфорт и конфиденциальность.

👤

Для клиентов

  • Прозрачное расписание: видно только реально свободные слоты.
  • Онлайн-оплата и моментальное подтверждение брони.
  • Возможность бронировать зал как на себя, так и на гостей.
  • Управление своими записями в личном кабинете (отмена, просмотр истории).
🛡️

Для администрации

  • Гибкая система ценообразования (базовая ставка + доплата за гостей).
  • Инструменты создания и редактирования залов и их оборудования.
  • Единый центр управления всеми бронированиями (включая создание записей за клиентов).
  • Аналитический дашборд с графиками выручки и загрузки.

⚙️ Техническая реализация

Проект спроектирован как надежный Full-stack сервис с упором на сохранность данных и отказоустойчивость. Архитектура построена по классической клиент-серверной модели.

Backend (.NET)

ASP.NET Core Web API. Использование изоляции транзакций (Serializable) для защиты от двойных броней. Фоновые службы (BackgroundService) для автоматического обновления статусов.

База данных

PostgreSQL + Entity Framework Core. Хранение массивов (оборудование) в нативных типах. Автоматическое применение миграций при старте приложения.

Безопасность

Ролевая модель доступа (JWT), хеширование паролей (BCrypt). Строгая валидация всех входящих данных, расчет стоимости только на стороне сервера.

Инфраструктура

Полностью контейнеризировано. Docker Compose позволяет развернуть весь стек (API + БД) одной командой за пару минут.
